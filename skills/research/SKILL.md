# research

Find enough reliable evidence to answer the question, with depth matched to uncertainty, stakes, and how fast the facts change. Before searching, identify what could settle the question. Retain the useful source material and decisive contradictions, and return the supporting evidence with the answer. A short answer may need only traceable citations; accepted task work retains its evidence for handoff and delivery. Use `artifacts` to package a larger evidence set, not to repeat the research.

1. Resolve only ambiguity that changes the research. Split independent questions when useful; set no source quota.
2. Prefer primary sources suited to the claim. Search snippets are leads: open each source used in the answer and check its date, context, dependencies, and limits.
3. Cross-check consequential or disputed claims. Separate observed facts, source claims, inference, and predictions. Investigate contradictions instead of picking the convenient source.
4. Stop when the answer is stable and remaining gaps are explicit. If evidence is missing, name what could decide the question instead of inventing certainty.

Cite claims near their supporting links. Explain only the disagreements and caveats that affect the decision. Add a separate source list only when it helps reuse. Public research does not authorize private-system changes, external communication, or saving a document.
